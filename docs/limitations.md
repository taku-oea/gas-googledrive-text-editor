# 既知の制限

[README](../README.md) から切り出した、既知の制限の一覧です。

## 配信先への到達性が前提

CodeMirror 6 などのライブラリは、`VENDOR_BASE_URL` の配信先から SRI 付きで読み込みます（[hosting.md](hosting.md)）。
**そこに届かない、または中身が SRI に通らないと起動できません**（その場合は
「エディタの読み込みに失敗しました」と原因を画面に表示します）。

esm.sh はスクリプトプロパティ `ESM_FALLBACK_ENABLED=true` のときだけ使うフォールバックです。
バージョンは `package.json` で固定し、esm.sh 側の URL は `tools/build.mjs` の `ESM_SH` に持っています。
更新するときは `npm view @codemirror/state version` などで確認して両方の数字を書き換え、`npm run build -- --apply` を流します。

CodeMirror 以外に `marked` / `dompurify` / `mermaid` / `fuzzysort` を載せていますが、
いずれも**使う場面になって初めて**読み込みます（プレビューを開いたとき、
` ```mermaid ` のブロックが現れたとき、パレットを開いたとき）。
mermaid は数 MB あるので、起動時の `modulepreload` にも入れていません。
バンドルでは mermaid と DOMPurify は同じインスタンスを共有します。

`?external=` でコアパッケージをバンドルさせず、bare specifier を import map で
1 つの URL に固定しているのが要点です。CM6 は `@codemirror/state` などが
同一プロセス内で 1 インスタンスであることを前提に設計されており
（Facet / StateField を参照同一性で識別する）、別コピーが読み込まれると
`Unrecognized extension value` で壊れます。

CDN 依存を無くしたい場合は、手元で一度 esbuild でバンドルし
`src/vendor-codemirror.html` として同梱する構成に切り替えられます。
CM6 の組み立ては `client/app/200-vendor.js` の `Editor`（`load()` と `buildState()`）に閉じてあります。

## 同じファイルを 2 つのペインには出せない

分割したペインに置けるのは別々のファイルだけです。VS Code のように「今のファイルを
複製して横に並べ、上と下を同時に見る」ことはできません。タブを 1 つのペインに固定する
代わりに、`EditorState` はタブが 1 つ持てば済み、複数ビュー間の同期が要らなくなっています。

`Mod+1`〜`Mod+9` はブラウザがタブ切り替えに使っていて奪えないため、ペインの移動は
`Alt+1`〜`Alt+6` に置いています。

## 比較は 2 つまで（3-way マージは非対応）

`@codemirror/merge` は 2 つの文書の比較しか扱いません。WinMerge の 3 ファイル比較や
共通祖先を使った 3-way マージはできません。

Google ドキュメント／スプレッドシート／スライドは本文を取り出せないので比較できません。
バイナリも同様です（一覧ではグレー表示のまま）。

大きいファイルでは差分の走査を `scanLimit: 3000` で打ち切ります。打ち切られた場合は
集計欄に「大きいので簡易比較」と出ます（行単位では正しく、語単位の精度が落ちます）。

比較の差分計算はブラウザ側で行うので、両方の本文が手元に必要です。
どちらも未取得のファイル同士を比べるときは、取得のための往復が 2 回走ります
（直接 Drive API なので 0.2〜0.5 秒 × 2、並列）。

## ターミナルはシェルではない

`bash` も `git` も `npm` も動きません。Apps Script の Web アプリにプロセスが無く、
ブラウザ側にもありません。動くのは `TERM_COMMANDS` に定義したコマンドだけです。

- **名前に `/` を含むファイルはパスで書けません**（`id:<Drive の ID>` で指してください）
- **同じフォルダに同名のファイルがあると、パスでは 1 つ目しか指せません**
  （`ls` で ID を確かめて `id:` で指すか、先に名前を変えてください）
- `cp` はファイルだけです。**フォルダのコピーには対応していません**
  （Drive の API に再帰コピーが無く、1 件ずつ作り直すことになるため）
- `**` の展開は 400 フォルダ・2000 件までです。超えると「範囲が広いため一部まで」と出ます
- `grep` は本文を全部ダウンロードして探します。`Mod+Shift+F` の全体検索とは別物で、
  あちらは Drive の全文索引で候補を絞ってから中身を見ます。**件数が多いときは
  全体検索のほうが速く、語の途中で当てたいときは `grep` のほうが確実**です
- `rm` はゴミ箱へ移すだけです。完全削除はしません（Drive 側で行ってください）
- 履歴は `localStorage` に残します。オリジンが変わると消えます（下の「localStorage の永続性」）

## セッションと未保存内容は別物

リロードで復元されるのは「どのファイルを開いていたか」までです。
**未保存の編集内容そのものはサーバーに送っていません**（下書きは localStorage のみ）。
リロード前に自動保存が完了していれば Drive から読み直されるので問題ありませんが、
保存に失敗したまま画面を閉じた場合の復元は下記の localStorage 依存になります。

## localStorage の永続性

`HtmlService` のサンドボックス iframe は
`https://n-<ランダム>-script.googleusercontent.com` という**再読み込みのたびに
変わりうるオリジン**で配信されます。そのため localStorage の下書きが
ページ再読み込みをまたいで残る保証がありません（同一セッション内では機能します）。
読み書きはすべて `try/catch` してあり、使えなくても動作には影響しません。

そのため保存に失敗したときだけ、同じ内容を Drive にも退避します
（[architecture.md](architecture.md)「未保存内容の保険」の `DraftStash`。直接 Drive API が使えるときのみ）。
セッションも `localStorage` に写しますが、正はサーバー側の記録です。

## drawio のプレビューは diagrams.net に依存する

図の XML は、ブラウザの中で `embed.diagrams.net`（JGraph Ltd）のページへ
`postMessage` で渡されます。描画はクライアント側で完結し、向こうのサーバーへ
送信はされませんが、**第三者のスクリプトに図を読ませることにはなります**。
また、利用者のネットワークから diagrams.net に到達できることが前提です。

気になる場合は、プレビューを開かなければ通信は発生しません（iframe はプレビューを
開いたときに初めて読み込みます）。ファイルそのものは XML としてエディタで開けます。

## HTML プレビューは 1 ファイル完結のものだけ

相対パスで隣のファイルを参照する HTML（`<link href="style.css">` など）は、
参照先を解決できません。Drive はファイルを HTTP のパスとして配信しないためです。
絶対 URL での読み込みは動きます。

また、入力のたびに `srcdoc` を入れ替える＝ページの再読み込みになるため、
プレビュー側の JavaScript の状態（入力途中のフォームなど）は保持されません。
縦位置だけは覚えて戻しています。

## オフライン非対応

`HtmlService` は IFRAME サンドボックスで動くため Service Worker を登録できません。
オフライン編集には対応しません。

## 保存直後の更新日時

通常の保存（ブラウザからの直接 API と、サーバーの REST 経路）は multipart の PATCH 1 本で書き、
その応答に入っている新しい `modifiedTime` をそのまま次回の競合検出の基準にするので、
この問題は起きません（[architecture.md](architecture.md)「高速化のために入れてあること」）。

REST が使えずに `DriveApp` の経路（`writeTextLegacy_`）へ落ちたときだけ、
`file.setContent()` の直後に Drive のメタデータが追いつかず、更新日時が保存前と
同じまま返ることがあります。その場合は最大 3 回・約 0.5 秒まで再取得を試み、
それでも変わらなかった場合は次回保存で競合ダイアログが出ることがあります。
「このまま上書き保存」で問題ありません（内容は失われません）。

## セッションの記録タイミング

タブを開く・閉じる・切り替える、フォルダを移動する、といった操作の 1.5 秒後に
まとめてサーバーへ記録します（キー入力では記録しません）。
操作の直後にリロードすると `google.script.run` の送信が間に合わないことがありますが、
同じ内容を `localStorage` にも即座に書いているので、同じブラウザで開き直す限りは
最後の操作まで戻ります。**別の端末で開いた場合と、再読み込みでオリジンが変わって
`localStorage` が読めない場合は、最後の 1 操作が反映されないことがあります。**

## 一覧の件数上限

1 フォルダあたりフォルダ 300 件・ファイル 500 件で打ち切り、
サイドバー下部に「件数が多いため一部のみ表示」と出します。
絞り込み（`Mod+Shift+E`）は**読み込み済みの階層の中だけ**を対象にするので、
未展開のフォルダの中身や、打ち切られたファイルは出てきません。
クイックオープン（`Mod+P`）はファイル名の索引も見ますが、索引も 1 フォルダあたりの上限は同じです。

## コピー／貼り付けはファイルのみ

クリップボードに入るのはファイル 1 件です。フォルダごとのコピーには対応していません
（Drive にフォルダを再帰コピーする API が無く、階層を辿って 1 件ずつ複製することになるため）。
フォルダの移動はドラッグ＆ドロップでできます。

## 作成・改名の制約

このエディタで開ける拡張子（`TEXT_EXTENSIONS`）以外の名前では作成・改名できません。
作っても一覧でグレー表示になるだけなので、サーバー側で事前に弾いています。
同じフォルダ内の同名も弾きます（Drive 自体は同名を許しますが取り違えの元になるため）。

名前の変更は Drive の更新日時も変えます。開いているタブの競合検出の基準値は
戻り値で自動的に差し替えていますが、**別のブラウザタブで同じファイルを開いている場合は
そちら側で競合ダイアログが出ます**。

## 削除はゴミ箱まで

`setTrashed(true)` によるゴミ箱への移動だけで、完全削除はしません。
誤操作は Drive のゴミ箱から復元できます。

## 一時メモの置き場所は「親フォルダ」までしか選べない

既定はマイドライブ直下です。誰でも必ず持っていて、かつ他人の目に触れない場所が
ここしかないためです。初回の選択画面と設定から**別のフォルダ（共有ドライブも可）へ
変えられます**が、選べるのは親フォルダまでで、一時メモが入るのは必ずその下に
アプリが作る `<アプリ名> / tmp` です。**既にあるフォルダをそのまま一時メモ置き場に
することはできません。** 保存期間を過ぎたメモを自動でゴミ箱へ移す掃除が、
そこに元からあったファイルまで巻き込むためです。

なお、一時メモを共有ドライブへ移すと **ファイルの所有者が共有ドライブに変わります**。
ドラッグでの移動時は確認を出しますが、保存ダイアログから選んだ場合と、
置き場所そのものを共有ドライブへ変えた場合は確認しません。

## 同じ一時メモを 2 つの端末で同時に編集すると競合する

一時メモは端末をまたいでタブごと復元されるので、両方の画面で書くと
通常のファイルと同じ競合検出に当たります（「別の場所で更新されています」）。
リアルタイムの同時編集はしません。後から保存した側が上書きするか、
やめるかを選ぶ形になります。

## その他

- 文字コードは UTF-8 と Shift_JIS だけです（EUC-JP・UTF-16 などは扱えません）。
  UTF-8 の BOM は、開いたときに付いていたファイルなら保存時にも付け直します
  （ステータスバーに `UTF-8 (BOM)` と出ます。付け外しも同じメニューからできます）
- UTF-8 としても Shift_JIS としても読めないバイト列を含むファイルは、**閲覧専用**で開きます。
  読めない部分は置換文字（`�`）で表示しているので、そのまま保存すると元のバイト列が失われるためです
  （タブ・比較ビュー・ターミナルのどこからも保存できません。内容は「新しいファイルに保存…」で書き出せます）
- パンくずは基準フォルダより上には遡りません。別の場所へ移るには
  ヘッダーの「フォルダを変更」を使います
- 個別に共有されたフォルダ（共有ドライブではなく「共有アイテム」）は
  選択画面のツリーに出てこないので、「URL または ID で追加」から指定してください
- 同時に開けるフォルダは 8 個までです（`MAX_ROOTS`）
